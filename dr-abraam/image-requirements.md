## Image Specifications

### Recommended Sizes:
- **Doctor Profile**: 400x400px (square)
- **Hero Images**: 1200x800px (landscape)
- **Clinic Photos**: 800x600px (landscape)
- **Logo**: 200x100px (transparent PNG)
- **Favicon**: 32x32px

### File Formats:
- **Photos**: .jpg (optimized for web, 80-90% quality)
- **Logos**: .png (with transparency)
- **Icons**: .svg (scalable vector graphics)

## How to Add Images

1. Download images from original website
2. Save them in the `images/` folder
3. Rename according to the list above
4. Run the image optimization script (I'll create this)
5. The website will automatically use the real images

## Alternative: Extract Images Manually

If you can access the original website, you can:
1. Right-click on images → "Save image as..."
2. Use browser developer tools to find image URLs
3. Download using wget or curl commands
4. Copy from local cache if recently visited
